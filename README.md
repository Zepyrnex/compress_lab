# File Compression Lab (demo)

1. Open this folder in VS Code
2. Terminal: `npm install`
3. Terminal: `npm run dev`
4. Open http://localhost:3000

Needs Node.js 18.17+ and an internet connection for the Google Fonts (Inter, Rajdhani); the page still works offline with fallback fonts.

Libraries: fflate (ZIP/Deflate), upng-js (PNG palette), pdf-lib (PDF), terser (JS), csso (CSS), svgo (SVG), @breezystack/lamejs (MP3).
